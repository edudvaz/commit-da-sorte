# 💻 Commit da Sorte

**Commit da Sorte** é uma aplicação web desenvolvida para facilitar a criação de rifas e a realização de sorteios de forma prática e intuitiva.

O sistema permite cadastrar participantes, garantir que não existam números repetidos, visualizar a lista de inscritos e realizar um sorteio aleatório para definir o vencedor.

---

## ✨ Funcionalidades

- ✅ Cadastro de participantes
- ✅ Validação para impedir números repetidos
- ✅ Listagem dos participantes cadastrados
- ✅ Sorteio aleatório do vencedor
- ✅ Interface responsiva
- ✅ Design inspirado em ambientes de desenvolvimento (tema dark)
